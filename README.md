# Hurricane Fleet

A playable canvas game: steer a battleship and aircraft carrier fleet through
worsening seas into a hurricane. Same fleet throughout, one run, no cuts.

- Steer the flagship carrier (drag, or ← → / A D); the two battleships and two
  destroyers hold formation behind it.
- Seas escalate: Calm Seas → Rough Seas → Storm → Hurricane, with heavier rain,
  lightning, rogue waves, whirlpools and debris.
- Each ship has its own health. A wrecked ship falls behind and the next one
  takes command. Lose all five and the round ends.
- Before each round, customise the sea: starting sea, wave height, rain and
  hazard density. Your choices are remembered.
- BOOST button to push through a bad patch, pause menu, restart, sound toggle,
  best distance and score saved on your device.

Open `index.html` in a browser to play — no server, build step or network needed.
Play it on the web: https://tkhn-tech.github.io/weather-fleet-muse-fix/ (enable
GitHub Pages on this repository first: Settings → Pages → deploy from the
`main` branch, root).
